Privacy rule (unchanged): rider names, addresses, and phone numbers stay inside the Microsoft 365 / org data boundary. The only AI allowed on rider data is Microsoft Copilot. Never paste rider PII into any outside AI tool.

What this approach is

A Microsoft 365–native version of the weekly scheduler built on Microsoft Lists (instead of raw Excel cells). You get a calendar-style editing surface, dropdown forms, color-coded views, and an Outlook email flow — all inside the tools the team already uses.
